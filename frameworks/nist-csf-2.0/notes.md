# NIST Cybersecurity Framework 2.0 Notes

## Relevance for AI-Enabled B2B SaaS

NIST CSF 2.0 is useful as a high-level cybersecurity risk management framework. It helps structure security activities across governance, asset understanding, protection, detection, response and recovery.

For this repository, NIST CSF 2.0 is used as a backbone for organizing security controls and communicating risk posture.

## Core Functions

| Function | Practical Meaning for SaaS |
|---|---|
| Govern | Define responsibility, risk strategy, policy and oversight. |
| Identify | Understand assets, data, systems, dependencies and risks. |
| Protect | Implement safeguards such as access control, secure configuration and awareness. |
| Detect | Identify security events through logging, monitoring and alerting. |
| Respond | Define and execute response processes for incidents. |
| Recover | Restore systems, services and trust after disruption. |

## Practical Control Areas

- Security ownership
