# GitHub Security Checklist

## Repository Governance

- [ ] Repository visibility reviewed
- [ ] Default branch protected
- [ ] Pull request reviews required
- [ ] CODEOWNERS configured
- [ ] Admin bypass reviewed
- [ ] Security policy added

## Supply Chain Security

- [ ] Dependabot alerts enabled
- [ ] Dependabot security updates enabled
- [ ] Dependency review enabled
- [ ] Lockfile committed
- [ ] Package manager defined

## Static Analysis

- [ ] CodeQL enabled
- [ ] CI workflow enabled
- [ ] Type checking enabled
- [ ] Security scanning reviewed

## Secrets Management

- [ ] Secret scanning enabled
- [ ] Push protection enabled
- [ ] No secrets committed
- [ ] .env ignored
- [ ] .env.example provided if needed
- [ ] Repository secrets reviewed

## Access Control

- [ ] MFA required
- [ ] Collaborators reviewed
- [ ] Least privilege applied
- [ ] Admin access minimized

## Evidence to Collect

- Repository settings screenshots
- Branch protection configuration
- Dependabot configuration
- CodeQL workflow file
- CI workflow file
- Security policy
- Access review notes
