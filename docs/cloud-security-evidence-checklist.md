# Cloud Security Evidence Checklist

## Identity and Access Management

- [ ] MFA enabled for privileged users
- [ ] Least privilege applied
- [ ] Role assignments reviewed
- [ ] Service accounts reviewed
- [ ] Privileged access documented

## Logging and Monitoring

- [ ] Cloud audit logs enabled
- [ ] Administrative events logged
- [ ] Authentication events logged
- [ ] Alerts configured for critical events
- [ ] Logs retained according to policy

## Network Security

- [ ] Public exposure reviewed
- [ ] Security groups or firewall rules reviewed
- [ ] Private networking considered
- [ ] Management interfaces restricted

## Data Protection

- [ ] Encryption at rest enabled
- [ ] Encryption in transit enabled
- [ ] Key management reviewed
- [ ] Storage buckets reviewed
- [ ] Database exposure reviewed

## Backup and Recovery

- [ ] Backups enabled
- [ ] Restore tested or documented
- [ ] Recovery objectives defined
- [ ] Business-critical assets identified

## Evidence to Collect

- IAM role export
- MFA policy screenshot
- Logging configuration
- Network security configuration
- Encryption configuration
- Backup configuration
- Monitoring and alerting rules
