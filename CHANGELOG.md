# Changelog

All notable changes to this project will be documented in this file.

## [0.1.0] - Initial Portfolio Release

### Added

- AI SaaS security and compliance fit-gap analysis lab.
- TypeScript-based analysis engine.
- Normalized control catalog.
- Evidence register.
- Local GitHub evidence collector.
- Remote GitHub evidence collector using GitHub CLI.
- Domain evidence ingestion for:
  - Application security
  - Cloud security
  - Privacy and data protection
  - AI governance
- Markdown, JSON and CSV fit-gap reports.
- Remediation roadmap generator.
- Executive readiness report generator.
- Risk score report generator.
- Portfolio project summary generator.
- Automated tests using Vitest.
- Repository validation script.
- GitHub Actions workflows for CI, CodeQL, report validation, evidence refresh and quality checks.
- Architecture documentation and Mermaid diagrams.
- Security assessment roadmap.
- AI governance templates.
- Privacy and GDPR-oriented templates.
- Cloud and application security review templates.

### Project Purpose

This release establishes the repository as a practical cybersecurity portfolio project for evidence-based security, compliance and AI governance assessment in AI-enabled B2B SaaS environments.

### Methodology

The project follows this chain:

~~~text
Framework -> Requirement -> Control -> Evidence -> Status -> Gap -> Risk -> Recommendation -> Roadmap
~~~

### Disclaimer

This project is for portfolio and technical demonstration purposes. It does not provide legal advice, formal audit conclusions or certification readiness guarantees.
