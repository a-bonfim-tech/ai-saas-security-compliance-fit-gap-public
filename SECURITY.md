# Security Policy

## Reporting a Vulnerability

This repository is a cybersecurity learning and portfolio project.

If you identify a security issue in the repository, please do not open a public issue containing sensitive details.

Instead, contact the repository owner privately through the communication channel listed in the GitHub profile.

## Scope

This policy applies to:

- Example scripts
- Configuration files
- Documentation
- Sample evidence files
- Control mapping logic

## Out of Scope

The following are out of scope:

- Legal compliance opinions
- Formal audit conclusions
- Certification readiness claims
- Attacks against third-party services
- Social engineering
- Denial-of-service testing

## Responsible Disclosure

Please include:

- A clear description of the issue
- Steps to reproduce
- Potential impact
- Suggested remediation, if available
