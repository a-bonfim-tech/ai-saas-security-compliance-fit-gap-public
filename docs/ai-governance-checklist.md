# AI Governance Checklist for B2B SaaS

## AI System Context

- [ ] AI system purpose documented
- [ ] Model provider documented
- [ ] Input data types documented
- [ ] Output data types documented
- [ ] User groups documented
- [ ] Business process impact documented

## Data Protection

- [ ] Personal data usage assessed
- [ ] Sensitive data usage assessed
- [ ] Data retention defined
- [ ] Data minimization considered
- [ ] Third-party processing reviewed
- [ ] Training, inference and logging data separated conceptually

## Security Risks

- [ ] Prompt injection risk assessed
- [ ] Sensitive data leakage risk assessed
- [ ] Insecure output handling assessed
- [ ] Abuse and misuse scenarios documented
- [ ] Logging and monitoring defined
- [ ] AI supply chain reviewed

## Oversight

- [ ] Human oversight defined
- [ ] Escalation path documented
- [ ] User transparency considered
- [ ] Risk ownership assigned
- [ ] Review cycle defined

## Evidence to Collect

- AI system description
- Data flow diagram
- Risk classification memo
- Human oversight procedure
- Prompt injection test notes
- User transparency notice
- Model/provider documentation
