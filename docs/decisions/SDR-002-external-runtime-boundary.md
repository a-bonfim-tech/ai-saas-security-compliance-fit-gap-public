# SDR-002 — External Runtime Evidence Boundary

Context: Repository documents cannot demonstrate external runtime IAM or logging effectiveness.
Decision: `AUD-002` and `AUD-005` remain `UNVERIFIED` without primary, product-bound runtime evidence.
Alternatives: infer from architecture; treat missing evidence as failure; accept examples.
Consequences: lower apparent scores but defensible conclusions.
Residual risk: real controls may exist but remain unevaluated.
Classification: Category C; Evidence Level D; Status: Proposta.
