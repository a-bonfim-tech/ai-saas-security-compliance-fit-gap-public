# Final Presentation Outline

## Title

AI-Driven Security and Compliance Fit-Gap Analysis for B2B SaaS

## Slide 1: Context

- B2B SaaS products need security and compliance evidence.
- AI-enabled products add privacy, governance and model-risk concerns.
- The project converts frameworks into controls, evidence, gaps and remediation priorities.

## Slide 2: Framework Scope

- NIST CSF 2.0
- ISO 27001
- SOC 2
- GDPR
- EU AI Act
- OWASP

## Slide 3: Methodology

Framework -> Requirement -> Control -> Evidence -> Status -> Gap -> Risk -> Recommendation -> Roadmap

## Slide 4: Evidence Sources

- GitHub
- Secure SDLC
- Application security
- Cloud security
- Privacy documentation
- AI governance documentation

## Slide 5: Automation

- Control catalog
- Evidence register
- TypeScript fit-gap engine
- JSON, CSV and Markdown reports
- Roadmap and executive report generation

## Slide 6: Key Findings

- What is covered
- What is partial
- What is missing
- What is high risk

## Slide 7: Remediation Roadmap

- P0/P1/P2/P3 priorities
- Engineering actions
- Governance actions
- Documentation actions

## Slide 8: Value to the Company

- Better customer readiness
- Better security visibility
- Better evidence traceability
- Better AI governance
- Better remediation prioritization

## Slide 9: Limitations

- Not a formal audit
- Requires human validation
- Requires real product and cloud evidence
- Legal conclusions require qualified review
