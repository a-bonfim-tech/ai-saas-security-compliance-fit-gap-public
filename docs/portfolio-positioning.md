## LinkedIn Project Description

I created an AI SaaS Security & Compliance Fit-Gap Automation Lab to practice and demonstrate how security and compliance requirements can be translated into controls, evidence and risk-rated remediation recommendations.

The project maps frameworks such as NIST CSF 2.0, ISO 27001, SOC 2, GDPR, the EU AI Act and OWASP guidance to evidence sources across GitHub, secure software development, cloud security, privacy and AI governance.

The repository includes a TypeScript analysis engine that generates Markdown, JSON and CSV reports for fit-gap analysis.

## Interview Explanation

This project is my practical preparation for cybersecurity work in AI-enabled SaaS environments. It shows how I approach security and compliance not as abstract paperwork, but as an evidence-based engineering and governance process.

The core logic is:

Framework -> Requirement -> Control -> Evidence -> Gap -> Risk -> Recommendation

## Value Proposition

For a SaaS company, this type of work helps answer:

- What security and compliance requirements apply to our product?
- What evidence do we already have?
- What gaps remain?
- Which gaps are risky?
- What should engineering, security and leadership prioritize next?
