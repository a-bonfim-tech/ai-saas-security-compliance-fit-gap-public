# Remediation Roadmap Model

## Purpose

The remediation roadmap translates fit-gap findings into prioritized implementation work.

## Priority Levels

| Priority | Meaning |
|---|---|
| P0 | Immediate remediation required. |
| P1 | High-priority remediation for significant exposure. |
| P2 | Planned remediation for medium-risk issues. |
| P3 | Low-priority improvement or documentation work. |

## Effort Levels

| Effort | Meaning |
|---|---|
| Low | Small documentation, configuration or validation task. |
| Medium | Requires coordination, implementation or review. |
| High | Requires cross-functional work, architecture decisions or governance input. |

## Roadmap Outputs

The roadmap generator produces:

~~~text
reports/roadmap/remediation-roadmap.md
reports/json/remediation-roadmap.json
reports/csv/remediation-roadmap.csv
~~~

## Use in a SaaS Company

The roadmap can support:

- Sprint planning
- Security backlog creation
- Compliance readiness planning
- Engineering prioritization
- Leadership reporting
- Customer security questionnaire preparation
