# OWASP Notes

## Relevance for AI-Enabled B2B SaaS

OWASP guidance is relevant for identifying common application security and AI/LLM security risks.

For this repository, OWASP is used to connect compliance requirements to practical application security controls.

## Web Application Security Areas

- Broken access control
- Cryptographic failures
- Injection
- Insecure design
- Security misconfiguration
- Vulnerable and outdated components
- Identification and authentication failures
- Software and data integrity failures
- Security logging and monitoring failures
- Server-side request forgery

## LLM and AI Security Areas

- Prompt injection
- Sensitive information disclosure
- Insecure output handling
- Excessive agency
- Overreliance
- Model denial of service
- Supply chain risks
- Data and model poisoning
- Unbounded consumption
- Insecure plugin or tool use

## Evidence Examples

- Input validation
- Authorization checks
- Secure session handling
- Dependency scanning
- Secret scanning
- Security tests
- AI risk assessment
- Prompt injection testing
- Output handling review
