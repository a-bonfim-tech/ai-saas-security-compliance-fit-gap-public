# Executive Reporting Model

## Purpose

The executive report translates technical fit-gap analysis into a leadership-readable summary.

## Audience

The intended audience includes:

- Founders
- CTO
- CISO or security lead
- Product leadership
- Engineering leadership
- Compliance or operations stakeholders

## Report Focus

The executive report focuses on:

- Readiness snapshot
- Key risks
- Main gaps
- Partially covered areas
- Recommended leadership actions

## Output

The executive report is generated at:

~~~text
reports/executive/executive-readiness-report.md
~~~

## Communication Principle

Executives usually need decisions, priorities and business impact. Technical details should remain traceable but not dominate the summary.
